## Description (English)

Sodium Tracker: Pinch Daily is a simple, friendly daily salt counter for keeping your sodium intake in view.

Set a daily sodium budget, log the food you eat, and see how much is left at a glance. Pinch keeps the focus on one clear number, with gentle encouragement instead of guilt.

**TRACK YOUR DAY**

- Set the sodium budget that suits your routine
- Search foods or quickly log milligrams yourself
- Organize entries by breakfast, lunch, dinner, and snacks
- See your remaining budget, recent patterns, and streaks
- Add gentle meal-time check-ins when you want them

**PINCH PLUS**

Unlock four-week trends, unlimited custom shelf foods, CSV export, and a home-screen sodium widget.

Food search is powered by FatSecret. Pinch is for personal tracking and is not medical advice; speak with a qualified clinician about a goal that is right for you.

## Subscription decision required

The supplied price image lists **Yearly $39.99**, **Yearly $29.99**, **Weekly $7.99**, and **Monthly $9.99**. The current iOS code supports only these two product IDs:

- `com.kabi.sodium.tracker.SodiumTracker.plus.yearly`
- `com.kabi.sodium.tracker.SodiumTracker.plus.monthly`

The safe release configuration is **Yearly $39.99** and **Monthly $9.99**. The $29.99 annual amount must be defined as either a separate product or an introductory offer, and the weekly plan must be added to the app code and paywall before it can be sold.

## Remaining App Store Connect requirements

1. Register `com.kabi.sodium.tracker.Sodium-Tracker` in Apple Developer. It is not currently available in the App Store Connect Bundle ID picker.
2. Create the App Store Connect app record using the values above.
3. Add the six product-page localizations above.
4. Upload a real 1024 × 1024 App Store icon. The current asset catalog declares icon slots but contains no icon image files.
5. Provide the support URL and a public privacy-policy URL. Neither URL is configured in this project.
6. Complete the App Privacy and age-rating questionnaires from the actual final data flow. Food searches are sent to FatSecret; its required attribution must be present before release.
7. Create the selected subscription products in App Store Connect, attach them to a subscription group, and provide subscription review metadata. Then connect/import them in RevenueCat if RevenueCat is to be used.
8. Upload App Store screenshots for every required iPhone display size and, if the app remains universal, iPad screenshots as well.

## RevenueCat status

The existing RevenueCat “Sodium Tracker (App Store)” app record has no Bundle ID saved and no connected App Store credentials. The iOS app currently uses StoreKit 2 directly, not the RevenueCat SDK. RevenueCat is therefore optional for the current binary, but it must be fully configured and integrated before relying on it for entitlements or paywall management.
